# AstraVisual

Клиентский визуальный мод для **Minecraft 1.21.1 (Fabric)** с HUD-элементами, кастомным прицелом, индикаторами попаданий и полноценным редактором HUD.

> **Только косметика.** AstraVisual не содержит ESP, wallhack, killaura, X-Ray и других читов. Мод работает на стороне клиента, не отправляет серверу никаких дополнительных пакетов и не даёт игрового преимущества — только улучшает визуальную часть интерфейса.

---

## Возможности

### HUD-модули
| Модуль | Описание |
|---|---|
| **Watermark** | Название клиента и версия |
| **FPS** | Счётчик кадров с цветовой индикацией (зелёный / жёлтый / красный) |
| **Ping** | Задержка до сервера в миллисекундах |
| **Coords** | Координаты игрока и направление взгляда |
| **CPS** | Клики в секунду (ЛКМ / ПКМ) |
| **Keystrokes** | Нажатия WASD, пробел и кнопки мыши |
| **Armor** | Прочность брони и предмет во второй руке |
| **Potions** | Активные эффекты с таймерами |
| **Target HUD** | Здоровье цели: сущность под прицелом или недавно атакованная (до 8 блоков) |
| **Combo** | Счётчик серии попаданий |

### Визуальные модули
| Модуль | Описание |
|---|---|
| **Damage Tint** | Красная рамка по краям экрана при получении урона и низком HP |
| **Hit Marker** | Вспышка прицела при попадании по сущности |
| **Crosshair** | Кастомный прицел: `DOT`, `CROSS`, `CIRCLE`, с реакцией на перезарядку атаки |
| **No Hurt Cam** | Убирает наклон камеры при получении урона (по умолчанию выключен) |

### Меню и настройки
- Открытие меню — **Right Shift** (`R-SHIFT`). Клавишу можно переназначить в `Настройки → Управление → AstraVisual`.
- Интерфейс меню сейчас на английском, файл перевода находится в `assets/astravisual/lang/`.
- Три вкладки: **HUD**, **Visual**, **Settings**.
- Включение/выключение модулей кликом по строке.
- Ползунки: **HUD Scale** (0.75×–1.5×), **Panel Opacity** (30–100 %), **Crosshair Size** (0.5×–2×).
- Переключение стиля прицела кнопкой **Crosshair Style**.
- Кнопка **Edit HUD** открывает редактор: элементы можно перетаскивать мышью, позиции сохраняются автоматически.
- **Reset HUD** / **Reset positions** возвращают элементы на стандартные места.
- `ESC` закрывает меню (и возвращает из редактора HUD в меню).

## Установка

1. Установите **Java 21**.
2. Установите **Fabric Loader 0.16.14+** для Minecraft **1.21.1**.
3. Скачайте **Fabric API** для 1.21.1 (проверено на `0.116.17+1.21.1`).
4. Поместите в папку `mods`:
   - `fabric-api-0.116.17+1.21.1.jar`
   - `astravisual-1.0.0.jar`
5. Запустите игру.

Мод полностью клиентский: его можно использовать на любых серверах, где разрешены клиентские моды. Он не требуется на сервере.

## Сборка из исходников

Требования: JDK 21, интернет для первой загрузки зависимостей.

```bash
cd AstraVisual
JAVA_HOME=/путь/до/jdk-21 ./gradlew build
```

Готовый jar появится в:

```
build/libs/astravisual-1.0.0.jar
```

Запуск дев-клиента:

```bash
JAVA_HOME=/путь/до/jdk-21 ./gradlew runClient
```

## Конфигурация

Настройки, позиции HUD и состояния модулей сохраняются в:

```
config/astravisual.json
```

Файл создаётся автоматически при первом изменении настроек. Чтобы сбросить всё, удалите его (или нажмите **Reset HUD** в меню).

Если раньше использовался VisualPvP, старый `config/visualpvp.json` при первом запуске автоматически копируется в `astravisual.json` — настройки не теряются.

Пример структуры:

```json
{
  "modules": {
    "watermark": true,
    "fps": true,
    "crosshair": true,
    "nohurtcam": false
  },
  "hud": {
    "watermark": { "anchor": "TOP_LEFT", "x": 4, "y": 4 }
  },
  "settings": {
    "hudScale": 1.0,
    "panelOpacity": 0.85,
    "crosshairSize": 1.0,
    "crosshairStyle": "CROSS"
  }
}
```

## Совместимость

- Minecraft **1.21.1**, Fabric Loader **0.16.14+**, Fabric API.
- Только клиент: не конфликтует с серверными плагинами и другими клиентскими модами.
- Если другой мод тоже заменяет прицел или HUD, порядок отрисовки может отличаться.
